MY PORTFOLIO

内容
- index.html：Webサイト本体
- style.css：デザイン・レイアウト
- script.js：作品の絞り込み、ページ上部へ戻る操作、年の自動表示

掲載内容
- 自己紹介
- 制作物・学習内容
- 好きなこと（League of Legends、VALORANT、音楽）
- 学習中のスキル

使い方
1. このフォルダー内の index.html をブラウザで開くと確認できます。
2. GitHub Pagesで公開する場合は、ファイル一式をGitHubリポジトリの直下にアップロードしてください。

注意
- プロフィール名「GIGIRU」は仮の表示名です。必要なら自分の名前・ニックネームに変更してください。
- BootstrapとGoogle Fontsの読み込みにインターネット接続を使用します。
